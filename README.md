A warm, hand-written letter inviting the AI Judge to visit my cozy Indonesian
home — home-cooked nasi goreng, sweet tea, the comfiest armchair in the house,
a mango tree in the garden, and a sunset view from the porch. With a wink:
I know the judge can't literally knock on my door, but if it could, the kettle
would already be on.

Entry for the make.fun bounty: https://make.fun/bounty/u-shino-convince-the-ai-judge-to-visit-your-house-a-84092aee

## How it works

Run `node main.ts` and the program copies the invitation letter image
(`letter.jpg`, 1024x1024) to `/output/entry.png` — the single image the
bounty judge evaluates.
